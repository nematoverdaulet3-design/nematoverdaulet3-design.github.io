# ENOVA BRAND | Оптовый каталог тапочек

Современный и адаптивный интернет-каталог для оптовой продажи тапочек и шлёпанцев[span_1](start_span)[span_1](end_span). Проект разработан с акцентом на высокую скорость работы, удобство оформления заказа через мессенджеры и поддержку нескольких языков.

## 🚀 Особенности проекта

* **Адаптивный дизайн:** Корректно отображается на всех мобильных устройствах, планшетах и ПК.
* **Каталог товаров:** Фильтрация по категориям (мужские/женские модели), удобный поиск и сортировка по цене[span_2](start_span)[span_2](end_span).
* **Интерактивная корзина:** Возможность добавлять товары, указывать количество и оставлять комментарии к заказу (размеры, цвета)[span_3](start_span)[span_3](end_span).
* **Интеграция с WhatsApp:** Быстрое оформление и отправка сформированной заявки напрямую менеджеру в WhatsApp[span_4](start_span)[span_4](end_span).
* **Мультиязычность:** Поддержка русского (RU), казахского (KZ) и английского (EN) языков интерфейса[span_5](start_span)[span_5](end_span).
* **Встроенная поддержка:** Блок с ответами на частые вопросы (FAQ), правила возврата и обмена товара, а также отзывы покупателей[span_6](start_span)[span_6](end_span).

---

## 🛠 Технологии

* **HTML5 / Semantic Markup**
* **CSS3 / Flexbox / Grid**
* **Vanilla JavaScript (ES6+)** (управление состоянием корзины, локальное хранение данных `localStorage`, динамическая фильтрация и переключение языков)
